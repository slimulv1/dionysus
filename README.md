# 🍸 Dionysus

> °˖* ૮( • ᴗ ｡)っ🍸 shheersh — Dionysus vers. 1.0

Rice config for **Hyprland** on Arch Linux, running on a **ROG Zephyrus G15** (_dionysus_).

## Features

- Animated **Neofetch**
- Dynamic **Waybar**
- ASCII **Cava Visualizer**
- Nord-inspired **neon-radioactive theme**
